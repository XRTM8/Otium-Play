# Otium Play

كل حكاية، بمكان واحد.

تطبيق Android وويب لمشاهدة الأفلام والمسلسلات عبر مصادر متعددة. اختر **قرمزي** للمسلسلات التركية، أو **سينمانا** للأفلام والمسلسلات. توفر سينمانا وملفات الفيديو يعتمد على شبكة المستخدم؛ ربط التطبيق لا يزيل قيود مزود الخدمة.

## التشغيل

```sh
npm install
npm start
```

افتح `http://localhost:3000`. نسخة Android تنفذ طلبات المصادر من شبكة الجهاز مباشرة ولا تحتاج Node server منفصلاً.

## المسلسلات والمشغل

- معلومات المسلسل مع قائمة حلقات عمودية، تصفية حسب الموسم، وبحث في الحلقات.
- بطاقات تعتمد على صورة المسلسل بدلاً من تنزيل صور كل حلقة، مع تمييز الحلقة الحالية وموضع المتابعة.
- HLS متكيف للمصادر التي توفره، واختيار جودة يدوي مع استكمال المشاهدة.
- سجل ومفضلة محليان، وواجهة RTL متجاوبة.

## التحقق

```sh
npm test
npm run test:ui
```

اختبارات المتصفح تحتاج Playwright ومتصفح Chromium محلياً. يمكن تحديد `PLAYWRIGHT_MODULE` و`BROWSER_PATH`.

## إصدار Android

راجع [SIGNING.md](SIGNING.md) لإعداد المفتاح الثابت. لا تُرفع ملفات المفاتيح إلى المستودع. بقي `applicationId` ومفاتيح التخزين القديمة ثابتين حفاظاً على البيانات وهوية حزمة Android بعد تغيير الاسم.

## الواجهات والأجهزة

- الهاتف: تصفح باللمس، شريط تنقل سفلي، وقائمة حلقات أسفل المشغل.
- الكمبيوتر: شبكة محتوى عريضة، تنقل جانبي، ومشغل مع الحلقات بجانبه.
- التلفزيون: تنقل علوي، كتابة كبيرة، تركيز واضح وتنقل D-pad؛ تفاصيل المسلسل والحلقات بعمودين.

يُكتشف Android TV من إعدادات الجهاز، وتوجد خانة **طريقة العرض** في المكتبة لاختيار التلفزيون يدوياً. يتضمن APK نفس الحزمة مع مُدخل Android TV Launcher وبانر خاص. واجهة المتصفح تدعم الشاشات الذكية المتوافقة؛ هذا لا ينشئ حزماً أصلية مستقلة لـ Tizen أو webOS.
